## 🚀 Flagship project

### 🛡️ [Purple-Team Lateral Movement Detection Platform](https://github.com/soukhnatali05/lateral-movement-detection-lab) &nbsp;·&nbsp; *Senior Capstone*

A fully Dockerized **red/blue cyber range**: a segmented enterprise network where an **inline IDS feeds a SOC triage dashboard**, adversary behavior is **emulated and mapped to MITRE ATT&CK**, and an **independent GRC platform maps live detection telemetry to NIST CSF, ISO 27001 and NCA ECC** — all under just-in-time, least-privilege access. One project that connects *attack, detection and compliance* in a single, reproducible lab.
